# Security reports

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Connorbelez/omarchy-hyprsplit-workspaces/security/advisories/new). Do not disclose credentials, biometric data, or a working exploit in a public issue. If GitHub reports that private reporting is unavailable, contact [the maintainer](https://github.com/Connorbelez) to arrange a private channel before sharing sensitive evidence.

Only the documented experimental baseline is under active review. There are no security support guarantees or stable release claims. Reports should include affected revision, impact, reproduction, and a proposed mitigation where available. Acknowledgments and advisories will credit reporters who consent.
